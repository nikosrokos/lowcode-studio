# LowCode Studio for VS Code / Cursor

Studio-like low-code RPA extension for Mac users who cannot run UiPath Studio Desktop.

See [`lowcode-studio/README.md`](lowcode-studio/README.md) for install and usage.

## Install quickly

```bash
cd lowcode-studio
npm install
npm run compile
npm test
npm run package
```

Then: **Extensions: Install from VSIX…** → select `lowcode-studio-0.1.0.vsix`.
